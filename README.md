# Simple Authentication

Project này demo cách sử dụng **Basic Auth** và **Cookie Auth** trong Node.js.

## 🚀 Cách chạy project

Cài đặt dependencies:
```bash
npm install
```

Chạy project:
```bash
npm start
```
